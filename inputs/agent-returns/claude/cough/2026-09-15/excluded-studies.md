# Excluded studies - `cough` (partial return)

A formal exclusion log with reasons per record **was not produced**, for the reasons set out in
`screening.md`. This file records the categories excluded and the specific items noticed and
deliberately set aside.

## Categories excluded

| Category | Reason |
|---|---|
| Commercial humidifier and air-purifier vendor content | Conflicted commercial source |
| Consumer health-site cough explainers | No traceable primary source |
| Patent applications surfaced by the search tool | Not evidence |
| Trial protocol boilerplate surfaced incidentally | Not results |
| Non-English sources | Language limit |
| Paediatric-only evidence used as adult evidence | Indirectness |

## Specific items noticed and set aside

- **Post-COVID cough real-world cohort (n=141, retrospective, single centre).** Set aside:
  observational, not randomised, specific to post-COVID cough, and reported a treatment preference
  rather than a controlled comparison. Could be reconsidered if a post-COVID cough sub-scope is added.
- **Traditional and herbal medicine trials** (including a Wolbigachul-tang protocol for upper airway
  cough syndrome). Set aside: out of the current module's intervention scope. Not judged on merit.
- **Gefapixant and camlipixant (P2X3 antagonists).** Recorded as context in `evidence-gaps.md` but
  excluded from claims: the population is refractory chronic cough, these agents are not standard in
  Australia, and the FDA issued a complete response letter for gefapixant in December 2023.
- **Interstitial-lung-disease cough studies.** Out of population scope.
- **Benzonatate.** Searched deliberately; **no evidence found that it is registered for supply in
  Australia.** Absence of a finding is not proof of absence - if the module later discusses it, the
  ARTG must be checked directly rather than relying on this return.
